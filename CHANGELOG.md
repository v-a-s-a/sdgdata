# Changelog

All notable changes to `sdgdata` will be documented in this file.

## 0.1.0 - 2026-06-06

- Initial `sdgdata` preview release.
- Added a Python client for SDG metadata and series data from the UNSD SDG API.
- Added Pydantic models generated from the UNSD SDG API schema.
- Added deterministic mocked tests backed by committed live-derived fixtures.
